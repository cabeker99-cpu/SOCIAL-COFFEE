ANTES DE USAR

Guia de implantação

1. Testar com segurança

Use nomes e situações inteiramente fictícios. Confira a clareza das perguntas e o funcionamento em celular e computador.

2. Validar institucionalmente

Consulte a TI e a área responsável por proteção de dados do IDR-Paraná antes de escolher hospedagem, autenticação e banco de dados.

3. Planejar o modo offline

Esta página pode armazenar registros localmente no navegador. O service worker permite abrir a interface após o primeiro carregamento online, em hospedagem HTTPS compatível. A sincronização entre dispositivos ainda não existe.

4. Criar uma versão real

Será necessário um backend ou serviço de dados autorizado, autenticação, regras de acesso, política de retenção, cópias de segurança e testes de segurança.

Não use este protótipo para decisões automatizadas. A pontuação é uma referência demonstrativa, não uma escala validada. Riscos imediatos e violações de direitos exigem avaliação profissional independente da pontuação. A técnica deve revisar, justificar e registrar a prioridade.

Limites desta versão

  • Não há login nem controle de acesso.
  • Os dados ficam apenas no navegador usado para preencher.
  • Não há sincronização entre produtores e técnica.
  • Não há envio real de formulários para servidor.
  • Não há coleta GPS nem mapa geográfico.
  • Não deve receber dados reais, sensíveis ou institucionais.
